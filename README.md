# Hewen's Portfolio

An interactive personal portfolio inspired by **Windows XP, Y2K interfaces, and scrapbook collage aesthetics**.

Instead of a traditional scrolling portfolio, the site presents my work and story through a playful desktop environment with overlapping windows, retro UI elements, interactive project previews, and personal collage details.

## ✦ Experience

The portfolio begins with an interactive flip-phone inspired landing experience before entering a Windows-style desktop.

Inside the desktop, visitors can explore:

- **Projects** — interactive previews of my software engineering projects
- **Experience** — my software engineering internship experience
- **My Journey** — a more personal look at my path from creative work to software development
- **About Me** — background and story
- **Contact** — ways to reach me
- **Collages** — pieces from my creative work before coding

## ✦ Featured Projects

- **Distributed Online Learning Platform** — high-concurrency learning workflows, distributed locking, Redis-based optimization, and real-time leaderboards
- **Movie Echoes** — full-stack movie review and social platform
- **SceneSound** — AI-powered music recommendation project
- **Temple Fantasy** — turn-based pixel RPG

## ✦ Built With

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## ✦ Design

The visual direction combines:

**Windows XP × Y2K × personal scrapbook**

The interface intentionally uses overlapping windows, desktop icons, retro dialogs, stickers, and small interactive details to make the portfolio feel less like a conventional résumé website and more like exploring a personal computer.
