# Hewen Portfolio

Phase 1 foundation for a personal software engineering portfolio.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion

## Local Setup

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Phase 1 Scope

This phase establishes the visual identity, flip-phone portal, multi-tap `HEWEN` interaction, short connection transition, scrolling collage framework, reusable retro UI components, placeholder content architecture, and one project-detail template.

Most portfolio content is intentionally placeholder-only.
